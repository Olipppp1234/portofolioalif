# Portfolio (React + Vite)

## Jalankan lokal
npm install
npm run dev

## Deploy ke Vercel
1. Upload folder ini ke GitHub, lalu Import di vercel.com
2. Framework Preset: Vite  |  Build Command: npm run build  |  Output Directory: dist

Edit konten di `src/data.js`. Warna & gaya di `src/styles.css`.
Background luar angkasa ada di `src/Starfield.jsx`.

## Logo skill
Link SVG ada di `src/icons.jsx` (`iconUrls`). Kalau satu link gagal dimuat, otomatis dipakai SVG inline sebagai cadangan.
